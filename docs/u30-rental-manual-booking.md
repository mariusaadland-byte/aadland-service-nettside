# U-30 – Manuell booking

Eierbeskyttet skjema for privatkunde, én produkttype/ett eksemplar og henting. Telefon eller personlig oppmøte. Samme prisberegning som offentlig booking, ny serverkontroll, separat depositum, verifisering av eksisterende booking/blokkering og forsinket utstyr. Bruker eksisterende atomisk booking-RPC (produksjonsdefinisjon kontrollert lesende) med pending_payment=false, som oppretter confirmed uten 30-minutters frist. Booking_number unik i DB; stabil UUID-basert nummerering ved samme forespørsel, kontroll av identisk innhold. Kunden registreres uten kundekonto; eksisterende konto-kobling kan skje senere. Admin registrerer kundens dokumenterte aksept; timestamp er registreringstid, ikke uavhengig bevis. Ingen automatisk e-post, Vipps, faktura eller betaling. Funksjon deaktivert som standard, og kan ikke opprette bookinger mens offentlig booking er åpen. Før aktivering: isolert testdatabase, dokumentert skriftlig aksept der nødvendig, atomisk vern for manuell blokk/for sen retur, kontroll av alle samtidige adminhandlinger, bekreft betalingsstatus og kunde-e-post, test duplikater og prisendring. Bedrift, levering, multiutstyr, timeslot, manuell rabatt, faktisk sendeflyt og betalingsintegrasjon gjenstår. Ingen produksjonsdata endret.
