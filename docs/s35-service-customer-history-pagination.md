# S-35 – Min side: eldre Service-historikk

Serveren beholder dagens første side (100 ordre, 100 tilbud, 50 direkte tegninger og 150 publiserte tegninger). Nytt avgrenset oppslag henter neste side for valgt kategori, med eksakt total der telling lykkes og stabil sekundærsortering på ID. Innlogging, e-post/bruker-ID, synlighetsfilter og private no-store beholdes. Utleieoppslag og auto-link kjøres ikke ved ekstra side; utleiehistorikken er uendret. UI legger til eldre poster uten å erstatte eksisterende, fjerner duplikater, prioriterer direkte tegninger og avviser svar fra tidligere konto/session. Tegningstotal teller kilder/versjoner, ikke unike tegninger; ordretotal gjelder alle Service-ordre samlet. Oversikten merker delvis innlastet historikk. Ved samtidige endringer kan offset-sider flytte seg; ny innlasting starter på første side. Syntetiske regresjonstester for 105 ordre, 101 tilbud, 202 tegningsoppføringer og kundeskille lagt inn i eksisterende build. Praktisk innlogget nettlesertest og produksjonsutrulling gjenstår.
