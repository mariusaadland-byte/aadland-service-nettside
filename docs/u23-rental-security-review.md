# U-23 – Sikkerhetsgjennomgang

25.11.2026: lesende kontroll av produksjonsdatabasen viste seks eksisterende rental_-tabeller (blocks, bookings, categories, deposit_alert_batches, deposit_inspection_events, items) med RLS aktivert, ingen direkte SELECT for anon/authenticated og ingen anon INSERT. Ingen policyer på disse tabellene. Dette er ikke fullstendig revisjon av alle funksjoner/grants eller alle API-endepunkter. Preview og produksjon har begge Supabase-konfigurasjon; lik database er ikke bekreftet. Ny eksplisitt produksjonssperre på ti utleiespesifikke mutasjonsruter, utleie-Vipps adminhandlinger, refresh og e-post fra offentlig betalingsstatus utenfor produksjon, samt automatisk kobling av utleiehistorikk fra kunde-me/login/verify. Eksisterende Service-handlinger endres ikke tilsiktet. Ingen endring av databasepolicyer eller miljøvariabler. Read-only preview kan fortsatt vise reelle data for autoriserte brukere dersom miljøene deler DB; krever isolert testdatabase og kontroll av preview-tilganger før full test. Shared webhook, cron, øvrige delte admin- og kunde-API-er, RLS/func privileges, IDOR, rate limit, private bucket og avvik i betalingsflyt må verifiseres i sluttkontroll. Ingen ekte kunde-, betalings- eller fototest utført.
