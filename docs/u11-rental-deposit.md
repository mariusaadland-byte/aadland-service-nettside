# U-11 – Depositum

Manuelt oppgjør: registrer faktisk mottatt/holdt depositum, dokumenter retur og eventuelle skader, registrer brukt beløp, tilbakebetal/frigi resten utenfor systemet og registrer først etter kontroll. Vis beregnet rest fra registrert holdt minus brukt. Returkontroll bruker samme forespørsels-ID ved retry; avvikende payload avvises. Ingen penger flyttes. Ingen automatisk Vipps-depositum, regnskapsføring eller skadefaktura er aktivert. Avklar dokumentasjon og faktiske trekk, og test separat før automatisering.
