# U-13 – Endring, avbestilling og forlengelse

Beholder gjeldende vilkår: før bekreftelse kan forespørsel endres/trekkes, etter bekreftelse kostnadsfritt frem til 24 timer før avtalt leiestart. Ingen nøyaktig klokkeslett beregnes fra dato alene. Min side gir ferdig utfylte e-poster til gjeldende kontaktadresse og telefon. Kunden sender selv; ingen serverregistrert forespørsel, automatisk endring, gebyr, betaling eller refusjon. Direkte admin-datoendring avvises i stedet for tidligere stille ignorering. Ved forlengelse gjelder opprinnelig returdato til ny avtale er godkjent. Full selvbetjening gjenstår: atomisk reservasjon med U-08, prisdifferanse og eksisterende betalings-/depositumstatus, godkjenning, hendelseshistorikk og test i isolert miljø. Vilkårsteksten får en praktisk kontaktanvisning; eksisterende frist er uendret. Ingen produksjonsdata endret.
