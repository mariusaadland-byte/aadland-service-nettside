# U-37 – Forbruksmateriell sammen med leie
Fase A: valg i leiehandlekurv og serververifisert prisforespørsel. Kjøpsvarer er valgfritt, engangsbeløp inklusive mva, separat fra leie og depositum. Kun aktiv vare tilknyttet valgt maskin, opp til 20 ulike varelinjer, 1–100 enheter, lagerkontroll ved lesetid; avvis duplikat og overbeløp. Kostpris og eksakt lagerantall sendes ikke til klienten. Ingen forhåndsvalgte varer. Ingen reservasjon, betaling eller lageruttak. U-31 checkout fortsatt av.
SQL-utkast er ikke kjørt. Tre eksisterende sperrer samt RENTAL_CONSUMABLES_ENABLED må vurderes før aktivering; behold av. Før salg: admin for SKU, kostpris, salgspris, kobling til flere maskiner ved behov, lager og lavlager; lagerbevegelser/revisjon, atomisk gruppetransaksjon med lagerlås/idempotens, utløp og tilbakeføring, retur/angrerett, faktura og Tripletex med separat salgslinje, riktig mva, Vipps/capture/refusjon, kunde- og BankID-avtale med immutable varelinjer. Tilbehør til retur må ikke blandes med solgte varer. Ikke legg til kjøp i eksisterende enkeltbooking før den kan lagre og belaste korrekt. Eksempelpriser er ikke lagt inn i produksjon.
