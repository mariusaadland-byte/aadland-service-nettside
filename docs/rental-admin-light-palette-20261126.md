# Utleieadmin – lys blågrønn palett

Eier foretrekker uttrykket på Utleieutstyr (lys bakgrunn, hvite kort, blågrønne knapper). Bruk eksisterende farger fra rentalInventory.module.css på dashboard, individregister, lønnsomhetskalkulator, depositum og Vipps-oppsett. Varsler beholder semantisk farge. Kontrasttest oppdatert til faktisk valgt palett med samme 4,5:1 minimum. Ingen global stilendring, ingen endring av offentlig katalog, Service eller betalingsinnstillinger. Mobil/PC-visuell kontroll gjenstår.
