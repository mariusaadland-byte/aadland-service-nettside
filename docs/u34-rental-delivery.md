# U-34 – Godkjente transportsatser

Godkjent av eier i samtalen 27.11.2026: 10 kr/km eks. mva. (12,50 inkl.), minimum 150 kr og maksimum 750 kr inkl. mva. per transportoppdrag/tur-retur før bom/ferge. Maksimal avstand 30 km én vei. Levering og innhenting er to tur-retur-oppdrag, egne bom/fergekostnader. Bom og ferge er tillegg utenfor prisgrensene. Satsene ligger fast i versjonert kode og lastes automatisk, ikke i redigerbar databaseinnstilling. Eier kan overstyre transportpris per tur-retur for beregningen med begrunnelse, ikke avstandsgrensen. Ingen data eller overstyring lagres. Utenfor grensen: separat tilbud. Faktisk kjøreavstand og bom/ferge må kontrolleres manuelt, og 0 må angis eksplisitt. Automatisk adresse/rute/takst-integrasjon, vedvarende redigerbare innstillinger, fast transporttilbud og integrasjon med bestilling/Vipps/Tripletex gjenstår. Offentlig levering sperret inntil dette er avklart. Ingen ekte bestilling eller betaling.
