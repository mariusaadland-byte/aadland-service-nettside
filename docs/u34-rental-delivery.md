# U-34 – Transportpris og leveringsområde

Intern eierbeskyttet kalkulator med faktisk kjøreavstand én vei, maksimal avstand, valgfri eksplisitt liste med postnumre, fast pris og kilometerpris samt bom/ferge per tur-retur, utkjøring/innhenting/begge. Beløp inkl. mva., depositum separat. Ingen forhåndsutfylte satser. Beregningen antar samme utgangspunkt og adresse, og to tur-retur-turer for både levering og innhenting. Manuelt kontrollert kjøreavstand, ingen kartintegrasjon, ingen lagring. Offentlig leveringsbestilling avvises på server og vises som levering etter avtale; tidligere pris uten transport skal ikke gi ny ubetalt leveringsforpliktelse. Henting selv uendret. Før automatisering: eiergodkjente satser og område, varig versjonert konfigurasjon, serververifisert kjørerute og gebyrer, fast tilbud med utløp og kundens eksplisitte totalprisaksept, integrasjon med booking/Vipps/refusjon/Tripletex og kapasitet. Ingen ekte bestilling, betaling eller dataendring.
