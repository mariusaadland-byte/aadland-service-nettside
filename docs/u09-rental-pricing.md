# U-09 — Prisberegning
Én felles prisfunksjon for kalender og booking. Døgn inkluderer begge valgte datoer. Eksisterende helgeregel (opptil tre dager som berører fredag/lørdag/søndag) er beholdt; helgepris må være billigere enn døgnprisene. Ukepris brukes for hele syvdagersperioder dersom den er billigere, resterende dager til døgnpris. Langtidsrabatt etter eksisterende produktgrense, depositum separat. Ugyldig nullpris på valgfri pakke ignoreres. Kunde må bekrefte samme leiepris og depositum ved innsending, ellers avvises booking før reservasjon. Gamle åpne faner uten forventet pris må oppdateres. Ingen eksisterende priser eller bookinger endres. Gjenstår: avklare eventuell annen helgeregel, gratisleie/100 % rabatt og teste med faktisk produkt, uten å utløse e-post eller betaling.
