# U-38J – Testpanel og databaseadapter
Owner-only testpanel /admin/utleie/signering/test med seks klikkbare tester og resultat per kontroll. POST /api/admin/signing/test bruker session, same-origin, rate limit og ingen caching. Test runner bruker ekte Node PDF-generator og signeringsfunksjoner med fiktivt ordregrunnlag, random testnøkkel, mock mail/lagring/RPC. Ingen kundeopplysninger, providerkall eller signeringsdatabase. Auth og rate limit bruker eksisterende system. Resultater er lokal visning, ingen permanent godkjenning.
U-38D draft RPC adapter mapper issue/revoke/commit parametere og feiler ved ukjent svar. Ikke koblet til produksjon, ingen grants eller nye live kundeendepunkter. Supabase listet aktiv produksjonsdatabase, ingen separate testgrener; ingen SQL kjørt eller testgren opprettet. Før videre: opprett isolert testdatabase etter avklart kostnad/tilgang, kjør U-37/U-38 SQL og samtidighetstester, real routes, outbox og betalingsflyt. Ingen produksjonsaktivering.
