# Utleieadmin – kontrastretting 26.11.2026

Eierens iPhone-skjermbilde viste nesten hvite overskrifter og gullknapp på lys kremflate. Rettet lokalt i dashboard, individregister/servicehistorikk og lønnsomhetskalkulator. Mørk tekst på eksplisitt lys bakgrunn, mørke knapper, mørke kort med lys tekst, gull som aksent, leselige inndata og fokus. Test beregner kontrast for sentrale fargepar (minst 4,5:1) og kontrollerer CSS. Ingen globale CSS-endringer, ingen aktivering av booking/Vipps, ingen dataendring. Visuell kontroll på faktisk iPhone/PC gjenstår.
