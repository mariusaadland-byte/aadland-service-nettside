# S-36 – sikker leverandørprislisteimport

Utkast. Begge import-API-er er lagt om til eierstyrt forhåndsvisning og eksplisitt aktivering. Privat RLS-beskyttet kladd lagrer validerte varelinjer og SHA256 av gjeldende leverandør/katalog. Forhåndsvisning viser nye/reaktiverte, endrede, opp/ned, deaktiverte og ugyldige rader. Ved minst 20 % bortfall kreves særskilt godkjenningsfrase. Kladder utløper etter 30 min, ubrukte kladder eldre enn 24 t ryddes ved ny forhåndsvisning. Aktivering låser katalogskrivere, sjekker fingerprint, gjør upsert og deaktivering og oppdaterer leverandørmetadata i samme transaksjon. Samme kladd kan ikke aktiveres to ganger. Eksisterende påslag og eksplisitt salgspris beholdes, egne varer er sperret, preview kan ikke skrive. CSV/TXT/TSV over 50 000 rader avvises fremfor stille avkorting. Syntetisk rollback-test bestod; etterkontroll 0 testvarer, 8991 aktive Bygger'n-varer, ny tabell ikke installert. Gjenstår: ny byggetest, faktisk rollback ved feil midt i aktivering, parallelltest og kapasitetsmåling på representativ 8991-raders syntetisk fil, innlogget UI-test, kontroll av alle øvrige importskrivere og godkjent migrasjon før merge. Ingen reell import eller permanent DB-endring utført.

## Verifikasjon 25.11.2026
- Full størrelse: 8991 gamle og 8991 nye syntetiske varelinjer i en rollback-transaksjon; 100 opp, 100 ned, alle 8991 salgspriser bevart. Målt SQL-forhåndsvisning 305 ms, aktivering 610 ms (ikke HTTP/filopplasting).
- Injisert feil ved siste journaloppdatering etter katalogskriving: fingerprint identisk med opprinnelig, ingen aktiveringsmarkør. To kladder mot samme katalog: andre kladd avvist etter første aktivering. Faktisk samtidige separate databasesesjoner ikke testet; låserekkefølge er harmonisert.
- Rolleprøve med SET LOCAL ROLE service_role bestått. Anon/authenticated mangler tilgang. Etter rollback: ingen testvarer, 8991 aktive Bygger'n-varer; kladdtabell ikke permanent installert.
- Søkt etter katalogskrivere i repo: begge masseimport-rutene er erstattet, manuell egenvare-rute separat. Ingen verifikasjon av eventuelle eksterne skript utenfor repo.
- UI viser uavklart aktivering korrekt etter nettverksfeil, samme kladd kan prøves igjen. Reell innlogget filopplasting, faktisk samtidighet og siste Vercel-build gjenstår.
