# U-35 – Digitale bruksanvisninger og sikkerhet

Separat dokumentregister per produkttype, med produsent, eksakt modell, språk, offisiell HTTPS-lenke og kontrollert supplerende sikkerhetsinformasjon. Eier/produktansvarlig kontrollerer dokument før ny versjon lagres. Append-only tabellutkast med RLS og service-role select/insert. Publisering krever separat flagg, siste versjon styrer synlighet; upublisert versjon skjuler tidligere versjon. Offentlig side viser bare aktivt, ikke skjult produkt med siste publiserte manual, ingen innlogging, ingen kundedata. QR peker til stabil produktside (UUID), ikke admin. Produkt kan ha flere fysiske enheter; modellen må kontrolleres for hver. Ingen dokument generert, hentet eller automatisk verifisert; lenkevalidering bekrefter ikke produsentens identitet. Ingen PDF-opplasting, ingen databaseendring eller flaggaktivering. For staging: installer utkast, kontroller grants, test parallell versjonslagring (optimistisk lesekontroll alene er ikke atomisk), og test lenker/QR-utskrift. Kundens tilgang til dokumenter for skjult utstyr under pågående leie må avklares før bruk. Ikke bruk dette som erstatning for produsentens instruksjoner, opplæring eller lovpålagt dokumentasjon.
