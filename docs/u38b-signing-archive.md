# U-38B – Avtaledokument og privat signeringsarkiv
Ny deterministisk Node PDF-generator fra serverens frosne ordregrunnlag, kunde, avtale-ID og revisjon. Inkluderer hele eksisterende utleievilkår 2026-11-25 fra versjonert JSX med løste kontaktverdier og lenkemål; 14 nummererte overskrifter. Ingen endring i publiserte vilkår. Samme input gir samme bytes og SHA-256. Endret revisjon gir nytt dokument. PDF er avtale til signering, ikke bekreftelse på betaling, og signeringsbevis er separat. Leie/varer/depositum adskilt. Ingen signert PDF/PAdES eller faktisk signeringshendelse. Renderer støtter WinAnsi; ved andre tegn stoppes genereringen heller enn å endre kundens navn. Må oppgraderes til Unicode-font før full lansering. Ingen nye pakker.
Privat databaseutkast bruker avgrenset bytea (maks 1 MiB) for små kontrakter, valgt for atomisk arkivering av eksakte PDF-bytes og kontrollsum uten separat storage-opplasting. Senere volum-/backupvurdering. Dokumentversjon, aktiv peker, kortlevd challenge og separat bevis. SHA-256 kontroll i DB, ingen offentlige grants, ingen runtime-tilgang ennå, RLS på alle tabeller. Bevisets eksakte tekst bevarer HMAC-serialisering. Utkastet ruller tilbake. Før migrasjon: test FKs og constraint, koble aktiv peker til samme gruppe/kunde (RPC og/eller kompositt-FK), sikre immutable dokument/bevis med begrensede grants, kontrollere auth og eierskap ved alle lesinger/skrivinger, lås gruppe/avtale/challenge ved signering, oppdater attempts atomisk, samlet rate limit, resend revokerer gammel kode, slett MAC etter bruk/utløp, nøkkelrotasjon. Ingen slette-/oppbevaringspolicy godkjent ennå.
Før ekte avtaler: juridisk gjennomgang av varekjøp og fjernsalg (inkl. angrerettskjema og separat anmodning om tidlig oppstart), kontakt- og partsvilkår, full leverings-/returtid, betalingsflyt, Unicode og visuell PDF-test, samsvar mellom arkiv og kundens viste bytes. Bruk serverberegnet snapshot fra gruppedatabase, ikke klient-JSON. Ikke la PDF-generering eller hash alene bekrefte signering. E-postkode og kundekopi gjenstår. Ingen produksjonsdatabase, e-post eller kundeavtale endret.
