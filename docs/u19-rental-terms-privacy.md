# U-19 – Utleievilkår og personvern

Versjon 2026-11-25 på egen URL, og gjeldende side peker dit. Nye bookinger må sende eksplisitt godkjenning og korrekt versjon; server lagrer versjon i eksisterende terms_version og serverregistrert godkjenningstid i eksisterende customer-JSON. Ingen ny migrasjon. E-post viser versjonslenke og admin viser nye godkjenninger. Tidligere bookinger endres ikke; arkivert kilde er teksten slik den sto ved U-19, ikke bevis for nøyaktig hva alle tidligere kunder så (U-13 endret teksten uten nytt versjonsnummer). Ikke bruk gammel versjonslenke som bevis. Oppdatering av personvernerklæring inkluderer utleiedelen, ikke påstand om aktiverte foto. Avklar rettslig grunnlag/interesseavveining, konkret lagringstid og sletting, leverandøravtaler/overføring, bedriftsvilkår og dokumentasjon på varig medium, angreskjema og uttrykkelig anmodning ved tidlig oppstart før full lansering. Vilkårstekst er forslag til praktisk presisering og må juridisk gjennomgås. Ingen kundedata endret eller e-post sendt. Datatilsynet: https://www.datatilsynet.no/rettigheter-og-plikter/virksomhetenes-plikter/informasjon-og-apenhet/hva-skal-virksomheten-gi-informasjon-om/ .
