# U-20 – SEO

Egen rental metadataBase, manifest, lokal bedriftsstruktur med Aadland Service som juridisk overordnet, ingen oppdiktede åpningstider/vurderinger. Service struktur flyttet til Service-forsiden. Rental-forsiden serverrendrer første katalogside fra aktivt offentlig produktutvalg, og oppdaterer fortsatt via eksisterende API. Sitemap inkluderer aktive ikke-skjulte produkter og personvern, returnerer 503 ved databasefeil fremfor å skjule produkter. Produkttitler/kanoniske URL-er og bilde-fallback forbedret. Ingen løfte om Google-indeksering eller plassering. Gjenstår: verifisere produksjonsdomene, HTML/robots/sitemap, indeksering via eierens Search Console, Business Profile hvis kvalifisert, publiser ekte produkter, test produktlenker og mobil. Ikke opprett fiktive produkter. U19 eldre S13 test forventet 21. november; oppdatert til faktisk ny dato 25. november uten å fjerne øvrige kontroller.
