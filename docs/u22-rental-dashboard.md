# U-22 – Utleieoversikt

Separat serverrendret adminoversikt med eksisterende rettigheter; eksakte booking- og produkttellinger, dagens utlevering/retur, forsinkelse og returnert ikke fullført. Eier får registrerte historiske betalingssummer, separat depositum, bare når alle rader er hentet og beløp gyldige (maks 1000 rader); ellers ukjent. Ingen nettofortjeneste eller lagerkapasitet antas. Lenker til eksisterende booking, kalender, produkt og depositum. Ingen dataendringer. Praktisk mobiltest, to roller, avstemming og skalering av finansaggregat gjenstår.
