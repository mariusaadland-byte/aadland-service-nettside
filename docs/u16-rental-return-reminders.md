# U-16 – Returpåminnelse

Eksisterende påminnelse før leiestart beholdes. Ny separat cron kl. 08 UTC (09 vinter/10 sommer i Norge) dagen før avtalt returdato, bare aktiv og ikke arkivert booking. Dato, utstyr og bookingnummer; ikke anta klokkeslett/sted. Separat varslingslogg med unik booking/returdato, ny kontroll etter claim, deterministisk Resend-idempotensnøkkel. Uavklart sending beholdes for manuell avklaring, ikke automatisk duplikat. Akseptert betyr at Resend aksepterte, ikke at mottaker leste e-posten. Maks 15 nye varsler per daglig kjøring blant første 100 treff; større volum, oppfølging av needs_review/claimed, senere samme-dag utlevering og samtidighetsvindu mellom statuskontroll og sending må løses før full drift. Ingen e-post sendt, ingen SQL kjørt og aktiveringsvariabel mangler/skal være false frem til verifisering. U-17 håndterer forsinket retur separat.
