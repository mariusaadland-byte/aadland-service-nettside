# U-29 – Reservasjon til eget oppdrag

Ny egen side for interne reservasjoner i utleieadmin. Bruker eksisterende rental_blocks med merket årsak, intern referanse og valgfritt notat. Ikke kundeordre eller regnskap. Eksisterende kalender viser eget oppdrag. Hele produkttypen sperres (alle eksemplarer); ikke individuell maskin eller faktisk relasjon til Service-ordre. Servervalidering, eier/produktrettighet, same-origin, gjenforsøk med UUID, kontroll av bookinger inkl. forsinket utstyr og overlappende manuelle blokkeringer. Offentlig booking må være stengt; det finnes fortsatt ikke atomisk sperre mot samtidige administrative endringer. Før lansering må transaksjonsvern og individuell tilordning ferdigstilles. Ingen migrasjon eller ekte reservasjon opprettet. Praktisk test gjenstår.
