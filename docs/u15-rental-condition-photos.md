# U-15 – Tilstandsbilder

Admin booking viser separate før-/etter-bilder. Kamerainngang og flervalg; opplasting ett bilde per forespørsel, maks 4 MB, JPG/PNG/WebP. Privat dedikert bucket, booking-ID/fase/admin-ID og hash; ingen overskriving eller sletting via UI. Server sjekker adminrettighet, bookingstatus, signatur og privat bucket; visningslenker 5 minutter. 100 bilder per fase er en forhåndskontroll, ikke atomisk kvote. Foto er ikke et uforanderlig arkiv, og EXIF-metadata kan følge filen; vurder fjerning av metadata og retention/personvern før oppstart. Bucket mangler i produksjon 25.11.2026, og SQL er kun utkast. Ingen produksjonsdata eller lagringspolicyer endret. Isolert opplastings-/rettighetstest, kontroll av brede storage-policies, kameraprøve på mobil og oppbevaringsrutine gjenstår før aktivering. Bilder er foreløpig valgfrie.
