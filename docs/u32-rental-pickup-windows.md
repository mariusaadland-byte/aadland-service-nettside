# U-32 – Henting og retur

Valgbare ønskede tidsvinduer for henting og retur per ukedag, for offentlig enkeltbooking og manuell privatbooking. Eierens åpningstider er ikke oppgitt, derfor ingen oppdiktede standardtider. Konfigurer RENTAL_PICKUP_WINDOWS_JSON og RENTAL_RETURN_WINDOWS_JSON som JSON-objekter med sun, mon, tue, wed, thu, fri, sat og lister av HH:MM-HH:MM. Eksempel kun for test: {"thu":["09:00-10:00","12:00-13:00"]}. RENTAL_PICKUP_WINDOWS_ENABLED må være true; av som standard. Server kontrollerer valgte vinduer, ukedag, norsk lokal tid, at vinduet ikke har startet og at samme dags retur ikke overlapper henting. Lagrer ønskede tider i eksisterende customer-JSON, ingen migrasjon. Vises i admin, Min side, registrerings- og bekreftelsesmail som ønsker, ikke bekreftede avtaler. Ingen e-post sendt. Ingen endring av leiepris, eksisterende bookinger, døgnkapasitet, avbestillingsfrist eller bookingbrytere. Faktisk timekapasitet, ferie/helligdagsunntak, adminstyrt bekreftelse/endring, tidsplan for levering og gruppestøtte gjenstår. Ingen aktivering før eier har bestemt åpningstider og gjennomført test.
