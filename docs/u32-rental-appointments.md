# U-32 – Henting og retur med tidsvinduer

Eierstyrt kalender med én avtale per 30-minutters tidsvindu, selvvalgte dager og tider, type henting/retur/begge. Ingen antatte åpningstider. Eksisterende bookinger med henting kan knyttes til et ledig vindu på riktig start-/sluttdato. SQL-utkast med unik dato/tid, én tildeling per booking/type, transaksjonslås og service-role tilgang. Ikke kjørt eller testet i DB. Ingen produksjonsdata endret. Funksjonen er av som standard og stengt når offentlig booking er åpen. Kundeinformasjon holdes utenfor slot-tabellen. Ingen endring av pris eller leiedatoer. Automatisk kundevalg ved booking, e-post/Min side, endring/frigivelse av tildelte vinduer, avbestillingskobling, servicekalender og DST-validering (tvetydige/ikke-eksisterende tider ved sommertidsbytte) gjenstår. Før aktivering må database, samtidighet, rolle og norsk tid testes i isolert miljø; ikke åpne offentlig booking. U31 har bestått forhåndsvisning og er slått sammen med main.
