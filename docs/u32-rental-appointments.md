# U-32 – Klokkeslett for utlevering og retur

Admin kan registrere manuelt avtalte klokkeslett på nye, bekreftede og aktive bookinger. Aktiv booking kan bare endre returtid. Ingen endring i pris, dato, kapasitet eller betalingsstatus. Lagring i eksisterende customer JSON, med registreringstid og krav om dokumentert avklaring med kunden. Oppdatering krever eksisterende canUpdateOrders, produksjon, same-origin, forventet updated_at og optimistisk DB-kontroll. Vises i kalender, Min side og fremtidig bekreftelsesmail. Lagring sender ingen e-post; kunden må informeres ved endring. Ingen standardtid eller oppdiktede åpningstider. Dette er ikke et timebookingsystem: samtidige utleveringer er ikke blokkert, sommertidsambiguitet ikke løst, og klokkeslett påvirker ikke dagsbasert forsinkelse eller avbestillingsfrist. Før offentlig selvbetjening: eier fastsetter åpningstider, tid per utlevering/retur, bemanningskapasitet, stengte dager, samtidighetsvern, endringsvarsling og juridisk fristberegning. Ingen eksisterende booking oppdatert. Praktisk testing gjenstår.
